# Create a New Trichoscopy Session

> Start a new trichoscopy analysis session for a patient to capture images and run AI-powered hair analysis.

## Prerequisites

- You have `patients.create` permission assigned to your staff role.
- The patient record already exists in your clinic.
- The patient does not already have an active (DRAFT) session of the same type.

## Steps

1. Navigate to the **Patient Page** for the relevant patient.
2. Click **Create Session**.
3. Select the **Session Type** — choose `HAIR_ANALYSIS`.
4. The system verifies no existing DRAFT session of the same type exists for this patient.
5. The session is created in **DRAFT** status and assigned to you.

## Notes

- A session can also be created from an **Appointment** — when an appointment is linked, the appointment ID is stored on the session record.
- **Session ≠ clinical visit.** A session represents the trichoscopy analysis workflow specifically, not the entire patient visit. Additional procedures (e.g., PRP treatment) happen outside the session.
- Only **one DRAFT session per type** is allowed per patient at a time. If a DRAFT session already exists, you must complete or delete it before creating a new one.
- Session data persists across logins — you can close the browser and return to continue later.
- DRAFT sessions can be deleted. SAVED and COMPLETED sessions cannot be deleted.
