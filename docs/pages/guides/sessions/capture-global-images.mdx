# Capture Global Images

> Take standard photographs from predefined positions to assess the patient's overall hair loss stage.

## Prerequisites

- You have an open session in **DRAFT** status.
- A camera or image capture device is connected.

## Steps

1. Open the **DRAFT session** for the patient.
2. Go to the **Global Images** section.
3. Select a **position** from the available options:
   - ANTERIOR
   - FRONTAL (required — at least 1 must be captured)
   - RIGHT_LATERAL
   - LEFT_LATERAL
   - POSTERIOR
   - LEFT_TEMPORAL
   - RIGHT_TEMPORAL
   - SUPERIOR
   - TOP_OF_THE_HEAD
   - VERTEX
4. Capture the image from the selected position.
5. Repeat for each desired position.

## Important Notes

- **At least 1 FRONTAL image is required** before the session can be saved. The system will reject the save without it.
- **Maximum 1 image per position.** If a position already has an image, capturing a new one replaces the existing image.
- **10 positions are available** in total. You do not need to capture all of them — only FRONTAL is mandatory.
- Global images are used by the AI to produce an overall **hair loss stage classification** based on all captured global images combined.
- Once the session is saved (status changes to SAVED), no more images can be added.
