# Compare Two Sessions

> View two sessions side-by-side to assess treatment progress by comparing images from matching positions.

## Prerequisites

- You have `patients.view` permission assigned to your staff role.
- The patient has at least two sessions of the **same type**.

## Steps

1. Navigate to the **Patient Page** for the relevant patient.
2. Select **Compare View** (found in the session history or actions area).
3. Choose **two sessions** of the same type to compare.
4. View the sessions **side-by-side**:
   - Images are matched by position — the same position from each session is displayed together.
   - Compare hair count, density, thickness, and visual changes between the two sessions.

## Notes

- **Only sessions of the same type can be compared.** You cannot compare a HAIR_ANALYSIS session with a future SKIN_TREATMENT session, for example.
- Images are matched **by position only** — the system pairs images that were captured from the same anatomical position.
- If one session has an image at a position that the other does not, that position will show data from only one session.
- This feature is useful for tracking treatment progress over time — compare an initial session with a follow-up to visualize improvement.
