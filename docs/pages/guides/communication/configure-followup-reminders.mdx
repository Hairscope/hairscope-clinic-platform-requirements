# Configure Follow-Up Reminders

> Set up automated reminders sent to patients after session completion to support treatment adherence and routine follow-up.

## Prerequisites

- **OrganizationAdmin** or **ClinicAdmin** role
- Access to Communication settings

## Steps

1. Navigate to **Communication → Follow-Up Rules**.
2. Click **Add Rule** to create a new follow-up reminder rule.
3. Configure the rule settings:
   - **Trigger**: `SessionCompleted` (fires after a session is marked complete)
   - **Offset** — time after session completion (e.g., 24 hours after, 7 days after)
   - **Channels** — which channels to use (email, WhatsApp)
   - **Template** — which notification template to use
   - **Recurrence** — `ONCE` (single reminder) or `RECURRING` with interval (e.g., daily for 30 days)
4. Click **Save** to activate the rule.

## Notes

- **Default rule** (provided until customized):
  - 24 hours after session: Email to Patient with report link
- **Recurring reminders** are useful for daily routine reminders (e.g., "Apply your treatment" for 30 days after a session).
- Recurring reminders continue until their configured end condition (end date, max count, or explicit cancellation).
- OrganizationAdmins and ClinicAdmins can both configure follow-up rules.
- The data model supports future extension to the Hairscope Care App (out of scope for current iteration).
