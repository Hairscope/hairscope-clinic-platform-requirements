# Set Channel Preferences

> Configure which communication channels are used for each notification type across your organization.

## Prerequisites

- **OrganizationAdmin** role (or recipient for personal overrides)
- Access to Communication settings

## Steps

1. Navigate to **Communication → Channel Preferences**.
2. For each notification type, configure:
   - **Primary channel** — the main delivery channel (e.g., Email, WhatsApp, SMS, In-App, Push)
   - **Fallback chain** — ordered list of alternative channels if the primary fails
   - **Multi-channel** — yes/no: whether to send on multiple channels simultaneously
3. Click **Save** to apply the preferences.

## Notes

- **Default preferences** (provided until customized):
  - Appointment reminders: Email (primary), WhatsApp (fallback)
  - AI analysis complete: In-App (primary), Push (fallback)
  - Report generated: Email (primary)
  - Security alerts: Email (primary), SMS (fallback)
- **Recipients** (staff or patients) can override Organization-level preferences for their own notifications, with the constraint that **transactional notifications cannot be disabled**.
- Recipient-level overrides take precedence over Organization-level preferences for non-transactional notifications.
- At least one channel must be configured for every notification type.
- All preference changes are recorded in the AuditLog.
