# Upload Medical Documents

> Attach medical documents (lab results, referral letters, prior records) to a patient's profile for centralized clinical record-keeping.

## Prerequisites

- You have `patients.edit` permission assigned to your staff role.
- The patient record already exists in your clinic.

## Steps

1. Navigate to the **Patient Page** for the relevant patient.
2. Scroll to the **Medical Documents** section.
3. Click **Upload**.
4. Select a file from your device:
   - Supported formats: **JPEG**, **PNG**, **PDF**.
   - Maximum file size: **10 MB**.
5. Enter a **Title** (required) — a descriptive name for the document (e.g., "Blood Test Results - Jan 2024").
6. Optionally enter a **Description** — additional context about the document.
7. Click **Upload** to confirm.
8. The document appears on the patient's page immediately after upload.

## Notes

- Files exceeding 10 MB will be rejected — reduce the file size or split into multiple documents.
- Only JPEG, PNG, and PDF formats are accepted. Other file types (e.g., DOCX, TIFF) are not supported.
- Documents are associated with the specific patient and will not appear on any other patient's page.
- Uploaded documents are recorded in the audit log.
- Documents can be deleted by staff with the appropriate permission.
