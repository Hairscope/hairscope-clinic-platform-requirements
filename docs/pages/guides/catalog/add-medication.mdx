# Add a Medication to Your Catalog

> Create a medication entry in your clinic's catalog so it can be recommended in sessions and included in prescriptions.

## Prerequisites

- You have `catalog.create` permission assigned to your staff role.
- Your clinic's currency is already configured (Settings → Clinic → Currency).

## Steps

1. Navigate to **Catalog** from the main menu.
2. Click **Create New Item**.
3. Select the type **MEDICATION**.
4. Fill in the required fields:
   - **Name** — the medication name.
   - **Description** — usage context or general information.
   - **Image** — upload a product image.
   - **Price** — the cost of the medication (must be 0 or greater).
5. Add a **Routine** (required for medications):
   - **Frequency** — how often the medication should be taken (e.g., "twice daily", "once a month").
   - **Duration** — how long the patient should continue (e.g., "6 months", "3 months").
   - **Instructions** — free-text application or usage notes (e.g., "take with food", "apply to affected area").
6. Optionally add an **External Link** — a URL where the patient can purchase the medication.
7. Click **Save**.

## Important Notes

- A **routine is required** for medications. The system will not allow you to save a medication without a complete routine (frequency, duration, instructions).
- When this medication is recommended in a session, the routine defined here is copied as a starting point. The doctor can customize it per patient.
- Medications appear in **Prescription** documents (separate from the Treatment Plan) and require a digital signature to generate.
- Currency is inherited from your clinic settings.
