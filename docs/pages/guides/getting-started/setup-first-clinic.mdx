# Set Up Your First Clinic

> Configure your clinic profile so that appointments, reports, and communications work correctly.

## Prerequisites
- Organization registered and logged in
- OrganizationAdmin or ClinicAdmin role

## Steps

1. Navigate to Clinic Settings.
2. Fill in the required fields:
   - **Clinic Name** (required)
   - **Address** (required)
   - **Timezone** (required — must be set before appointments can be booked)
3. Configure recommended fields:
   - **Currency** (required before catalog items can be created)
   - **Language** (determines the language of all generated documents)
   - **Working Hours** (per day — start time, end time, or mark as closed)
   - **Phone** and **Email**
   - **Website URL**
4. Upload your clinic logo (JPEG/PNG, max 10MB).
5. Configure the Report Header (logo, clinic name, address — appears on all generated PDFs).
6. Add Terms & Conditions text (included in all generated reports).
7. Save the clinic profile.

## Important Notes
- Timezone must be set before the Appointments module can be used.
- Currency must be set before the Catalog module can be used.
- Working hours define when appointment slots are available to patients.
- Language setting determines the locale for all generated documents (reports, treatment plans, prescriptions, invoices). Documents remain in the configured language permanently.
