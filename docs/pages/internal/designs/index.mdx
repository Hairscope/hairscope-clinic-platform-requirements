# Hairscope Clinic Platform - Master Designs

> Covers: System architecture, repository structure, domain modeling, authentication, authorization, data layer, event processing, GraphQL architecture, engine architecture, storage, observability, audit architecture, testing strategy, deployment, security, and performance.

---

## Architecture Overview

```
Modular Monolith Core (single deployable)
├── Modules (own domain state + business logic):
│   ├── IAM
│   ├── Organization
│   ├── Audit
│   ├── Patients
│   ├── Sessions
│   ├── Appointments
│   ├── Leads
│   ├── Catalog
│   ├── Billing
│   └── Communication Policy
│
├── Engines (stateless, deterministic, no side effects):
│   ├── Access Resolution Engine
│   ├── Entitlement Engine
│   ├── Lead Distribution Engine
│   ├── Smart Scheduling Engine
│   └── Recommendation Engine
│
└── Platform Infrastructure:
    ├── Transactional Outbox
    ├── Event Bus
    ├── File Storage
    └── GraphQL API Layer

Separate Worker Services (stateful async infrastructure)
├── Reminder Service
├── Notification Service
├── AI Models
└── Report Generation Service
```
