## v1.0.0 — 2026-05-14

### Initial Release
- 8 implementation documents covering tech stack through deployment
- Next.js 16 with App Router and Server Actions
- Apollo Client for GraphQL (queries, mutations, subscriptions, file uploads)
- Zustand for client-side UI state
- Tailwind CSS + shadcn/ui for styling and components
- Server Actions for auth flows (login, refresh, logout via httpOnly cookies)
- Role-based routing and navigation
- Vitest + Playwright testing strategy
- Docker deployment with standalone output
