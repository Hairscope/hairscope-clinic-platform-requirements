# Review a Draft Invoice

> Examine the automatically generated invoice after a session is completed, verifying that all line items are correct before finalization.

## Prerequisites

- Staff account with billing view permission
- A session must have been marked as **COMPLETED** (which triggers automatic invoice generation)

## Steps

1. Navigate to **Billing** from the main navigation menu.
2. Find the **draft invoice** — it is auto-generated when a session is completed.
3. Review the auto-populated **line items**:
   - The **service** from the linked appointment (if the session had a linked appointment)
   - All **recommended catalog items** from the session (medications, cosmetics, supplements)
   - Treatment Kits appear as a single line item with the bundle price
4. Verify quantities, prices, and totals are correct.
5. Make any necessary adjustments (add manual items, charges, or discounts) before finalizing.

## Notes

- While the invoice is in **DRAFT** status, it **auto-syncs** with session recommendations: if recommendations are added, edited, or removed (including strike-through edits on Treatment Plan/Prescription), the corresponding auto-generated line items update automatically.
- **Manual line items** added by staff are never auto-removed during sync.
- If the session had no linked appointment, the invoice contains only recommended catalog items (no service line item unless manually added).
- Zero-item and zero-total invoices are valid — staff may add line items later.
- Each invoice is associated with exactly one session and one patient.
